# Password Manager

## Overview

This project is a command-line password manager developed in Python. It allows users to securely store and manage passwords using SHA-256 hashing and JSON-based storage.

## Features

* Add new account credentials
* View stored account information
* Store passwords in a JSON file
* Hash passwords using SHA-256 for increased security
* Simple command-line interface

## Technologies Used

* Python
* JSON
* hashlib (SHA-256)

## How to Run

1. Download or clone the repository.
2. Open the project in an IDE such as PyCharm.
3. Run `Password Manager hash .py`.
4. Follow the on-screen prompts.
